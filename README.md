# ChatReminder
A little tool for Tampermonkey that sends warning to update the customer

## Installation
1. Installiere Tampermonkey
2. Klicke hier zum Installieren: https://github.com/ChristikChris/ChatReminder/main/ChatReminder_user.js

## Beschreibung
Reminds associates to update customers during chat cases in Paragon (5-minute cadence) + Patience quick-fill

## Features
- 5-minute reminder cadence
- 7-minute urgent reminder
- Multilingual patience phrases (EN, ES, DE)
